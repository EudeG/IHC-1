# App de rentabilidad para microemprendimientos

## Integrantes

- Contreras Garzón Job Natanael
- Flores Veizaga Eudenia Gandira

## Tipo de proyecto

Aplicación móvil para calcular la rentabilidad de una idea de microemprendimiento.

## Modalidad

Proyecto académico desarrollado de manera grupal, en pareja.
s

## Problema inicial

Las personas que quieren emprender tienen una idea de negocio, pero no saben cuánto necesitan invertir ni si esa idea realmente será rentable antes de arrancar.
Suelen dudar entre varias ideas sin un criterio claro para comparar cuál conviene, y al no tener formación en finanzas, les cuesta traducir su idea en números concretos.
